# 👑 विवाह निमंत्रण पत्रिका (Royal Wedding Invitation)
### **हृदयांश राहुल संग हृदयांशी शिल्पा — रामजे परिवार, इन्दौर (म.प्र.)**

एक आधुनिक, लग्जरी एवं पारम्परिक डिजिटल विवाह निमंत्रण वेबसाइट (React 18 + Vite), जिसे विशेष रूप से मालवा/इन्दौर की सांस्कृतिक भव्यता और सनातन हिन्दू विवाह संस्कारों को ध्यान में रखकर तैयार किया गया है। यह वेबसाइट विशेषतः मोबाइल और व्हाट्सएप पर साझा करने के लिए ऑप्टिमाइज़्ड है।

---

## 🌟 प्रमुख विशेषताएं (Key Features)

1. **एकल डेटा फाइल नियंत्रण (`src/data/invitation.js`)**:
   - सभी नाम, पूर्वज, पारिवारिक सूचियां, कार्यक्रम, समय, स्थल, श्लोक, फोन नंबर एवं व्हाट्सएप संदेश इसी एक फाइल में सुरक्षित हैं। किसी भी React कम्पोनेंट को छुए बिना संपूर्ण निमंत्रण आसानी से संपादित किया जा सकता है।

2. **पारम्परिक शाही डिजाइन (Royal Modern-Traditional Soul)**:
   - **रंग योजना**:
     - *Light Mode*: Ivory (`#FFF8EC`), Deep Maroon (`#7A1F2B`), Antique Gold (`#C9A24B`), Marigold Orange (`#E8912D`), एवं सॉफ्ट क्रीम कार्ड्स।
     - *Dark Mode*: Deep Maroon-Black (`#14090B`), Warm Gold (`#E5C378`), एवं Muted Cream (`#F5EBE1`)।
   - **फोंट्स**:
     - Google Fonts: *Yatra One*, *Tiro Devanagari Hindi*, *Mukta* एवं *Cormorant Garamond*।
   - **शुद्ध SVG एवं CSS अलंकरण**:
     - श्री गणेश एवं स्वास्तिक मंगलीक प्रतीक
     - तोरण (गेंदे के फूल एवं आम के पत्तों की माला)
     - मंद-मंद झिलमिलाते दीप (Floating Glowing Diyas)
     - मंडला एवं रंगोली सेक्शन डिवाइडर्स
     - कार्ड्स पर पारम्परिक पैस्ले (अम्बी) कोने
     - बिना किसी भारी इमेज के बिजली जैसी तेज़ लोडिंग स्पीड (Lighthouse 95+)।

3. **भव्य उद्‍घाटन एनिमेशन (Curtain / Patrika Unfold)**:
   - पेज लोड होने पर राजसी सुनहरे कपाट एवं **"निमंत्रण खोलें"** बटन दिखाई देता है, जिसे दबाते ही द्वार खुलकर मुख्य निमंत्रण पत्र प्रस्तुत करते हैं।

4. **अतिथियों हेतु व्यक्तिगत आमंत्रण (Personalized Guest Link)**:
   - लिंक में `?guest=शर्मा+जी` जोड़ने पर स्क्रीन पर विशेष रूप से:  
     *"प्रिय शर्मा जी, आपका एवं आपके परिवार का हार्दिक स्वागत एवं अभिनंदन है"* प्रदर्शित होता है।

5. **जीवंत उलटी गिनती (Live Auspicious Countdown)**:
   - 11 दिसम्बर 2026, सायं 7:00 बजे (शुभ लग्न एवं बारात प्रस्थान) हेतु दिन, घण्टे, मिनट एवं सेकण्ड की जीवंत उल्टी गिनती।

6. **मांगलिक कार्यक्रम रूपरेखा (Interactive Events Timeline)**:
   - 6 पावन कार्यक्रम (खलमिट्टी, माता पूजन, मण्डप, बारात प्रस्थान, शुभ लग्न फेरे, एवं 13 दिसम्बर का आशीर्वाद समारोह तथा स्वरुचिभोज)।
   - डेस्कटॉप पर अल्टरनेटिंग कार्ड्स एवं मोबाइल पर वर्टिकल टाइमलाइन।
   - प्रत्येक कार्यक्रम हेतु **Google Calendar** लिंक एवं Apple/Outlook **.ics फाइल डाउनलोड**।

7. **आशीर्वाद समारोह एवं स्वरुचिभोज (13 दिसम्बर Spotlight)**:
   - 13 दिसम्बर के मुख्य प्रीतिभोज को भव्य कार्ड एवं विशेष सजावट के साथ हाईलाइट किया गया है।

8. **गूगल मैप्स नेविगेशन (Venue Directions)**:
   - **निज निवास** (जी-55, लाहिया कॉलोनी, खाटू श्याम मंदिर के पास, कबीटखेड़ी, इन्दौर)
   - **गजानंद मंगल परिसर** (भागीरथ पुरा, इन्दौर)
   - एक-क्लिक में Google Maps दिशा-निर्देश तथा एक-क्लिक में पता कॉपी करने की सुविधा।

9. **पारिवारिक स्नेह (Accordion Folders)**:
   - प्रेषक, दर्शनाभिलाषी, स्वागतातुर, विनीत एवं बाल मनुहार ("हमारे मामा/चाचा की शादी का शुभ अवसर आया है...") हेतु सुंदर व सुव्यवस्थित एकॉर्डियन।

10. **व्हाट्सएप RSVP / आशीर्वाद पुष्टिकरण**:
    - नाम, सदस्यों की संख्या एवं शुभकामना संदेश दर्ज करके सीधा व्हाट्सएप पर प्री-फिल्ड देवनागरी संदेश भेजने की सुविधा (`wa.me/918109860849`)।

11. **मांगलिक शहनाई संगीत (Music Engine)**:
    - बैकग्राउंड शहनाई वादन (ब्राउज़र नीतियों के कारण डिफ़ॉल्ट रूप से म्यूट)।
    - यदि कोई लोकल MP3 उपलब्ध न हो, तो भी बिल्ट-इन **Web Audio API** आधारित राग यमन शहनाई व तानपुरा सिंथेसाइज़र अपने आप वास्तविक पारम्परिक संगीत बजाता है!

12. **लाइट एवं डार्क मोड टॉगल**:
    - पूर्ण CSS वेरिएबल्स आधारित, सिस्टम थीम ऑटो-डिटेक्ट एवं लोकल स्टोरेज में वरीयता सुरक्षित।

## 🚀 चलाने के निर्देश (How to Run Locally)

### 1. डिपेंडेंसी इंस्टॉल करें:
```bash
npm install
```

### 2. डेवलपमेंट सर्वर शुरू करें:
```bash
npm run dev
```
ब्राउज़र में `http://localhost:3000` (या टर्मिनल में दिखाए गए URL) को खोलें।

### 3. प्रोडक्शन बिल्ड तैयार करें:
```bash
npm run build
```
यह `dist/` फोल्डर में ऑप्टिमाइज़्ड प्रोडक्शन फाइल्स तैयार कर देगा।

## 🌐 होस्टिंग एवं परिनियोजन (Deployment)

### Vercel पर:
1. `vercel` CLI चलाएं अथवा [vercel.com](https://vercel.com) पर गिट रिपॉजिटरी इम्पोर्ट करें।
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`

### Netlify पर:
1. [netlify.com](https://netlify.com) पर नया प्रोजेक्ट बनाएं।
2. Build Command: `npm run build`
3. Publish Directory: `dist`
